### HBX-Forge CI Pipeline

**Status:** 4 consecutive failures (20–27 Aug). All failures traced to one root cause:

```
npm ci  →  fails because package-lock.json is missing
```

The CI workflow uses `npm ci` in 4 separate jobs, but only `package.json` was committed — no lockfile. `npm ci` requires an up-to-date `package-lock.json` and will exit non-zero if it can't find one.

**Fix in progress:** Patch the workflow to use `npm install` instead of `npm ci`, and point `cache-dependency-path` at `package.json` (which exists) rather than the missing `package-lock.json`. This is a 7-line change across 4 job definitions. Pushed to `main` and confirmed.

**After fix:** CI should pass on next push. The `npm install` will generate `package-lock.json`, which then becomes valid for future `npm ci` calls.
