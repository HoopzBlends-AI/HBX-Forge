### Dashboard

`apps/dashboard/` — Next.js 14 frontend for the Mission Control interface.

**Status this week:** Code committed. 10 source files. 2 screens implemented (Dashboard Home + Mission Control). 6 more screens planned (Task Force, SITREP, Country Profiles, Security Center, Build Pipeline, Agent Roster, Settings).

The dashboard code is in the repo. It has not been built or deployed. It needs:
1. `package-lock.json` (will be generated by CI's `npm install`)
2. A successful CI build
3. A Netlify deployment

### Build Engine

HBX-Forge is designed to be an autonomous build engine — it plans, codes, tests, secures, and deploys the modules with human approval gates at life-safety boundaries.

**Status this week:** The build engine is the monorepo itself, plus the CI pipeline. The "autonomous" part (AI-driven code generation, automated PRs, self-healing) is not built yet. That is a future phase.
